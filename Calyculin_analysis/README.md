# README Calyculin_analysis

This notebook plots the results of an experiment that asks the question "Can we prevent pancreatic cancer organoids growth, shifting from an 'Extension phase' to a 'Lumen formation phase'".
More specifically, we check whether we can prevent the formation of cavities (lumens) by increasing the contractility of cells, through the addition of a compound call Calyculin-A.

Results of this experiment are stored in an Excel file, that is read and processed by the Jupyter notebook.
Figures can be produced and are shown in the Graphs folder.

Read the whole paper in Open Access on: https://www.cell.com/iscience/fulltext/S2589-0042(24)01524-4
