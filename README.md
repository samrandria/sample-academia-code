# README
Some samples of Python code written for data analysis. 

This repository is here to showcase some of the Python code written for the analysis of pancreatic cancer research data. 
It contains code for:

- Dataset loading and processing
- Data visualisation
- Statistical analysis
- Production of publication-ready figures

Please note that this is _self-taught_, Python code written for _academia_ and not _production_: as such, some of the pandas is less than idiomatic and could benefit from a rewrite.

The full datasets, codes, and outputs can be checked in the Zenodo repositories of the published papers:
