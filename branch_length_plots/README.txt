# Note

In the folder "Script", the Jupyter notebook "branching_lengths_plots" will produce the graph visible in Fig. S5e (exporting it in the folder "Graphs" if you uncomment the plt.savefigs() calls), by parsing the csv track files located in the "csv" folder.

This notebook checks the "branches" lengths of the "trees" that pancreatic cancer-derived organoids form, to see if the "branching" process follows an exponential law.

This was used to produce Figure S5.e : https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41467-022-32806-y/MediaObjects/41467_2022_32806_MOESM1_ESM.pdf

Check out the whole paper at : https://www.nature.com/articles/s41467-022-32806-y
